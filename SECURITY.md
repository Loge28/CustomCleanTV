# Security Policy

CustomCleanTV interacts with Android TVs over network ADB and installs a custom launcher environment. Security is taken seriously to ensure user safety in their living rooms.

## Supported Versions

| Version | Supported |
|---|---|
| `main` branch | ✅ Yes |
| Older releases | ❌ No |

## Reporting a Vulnerability

If you discover a security vulnerability or potential risk:
1. **Do not disclose it publicly** via public GitHub issues.
2. Report it through the repository's [Security Tab](https://github.com/Loge28/CustomCleanTV/security/advisories/new) via GitHub Private Vulnerability Reporting.
3. Include detailed steps to reproduce the issue, affected devices/firmwares, and potential impact.

Valid vulnerabilities will be patched promptly in the main branch.
